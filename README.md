**Descripción**:

Este repositorio reúne una serie de cuadernos desarrollados con el objetivo de introducir y consolidar los fundamentos del lenguaje de programación Python. A lo largo del trabajo se abordan los principales tipos de datos, estructuras de almacenamiento, mecanismos de control de flujo, funciones y nociones básicas de programación orientada a objetos, los cuales constituyen la base para el desarrollo de aplicaciones funcionales y estructuradas. Este repositorio tiene como propósito fortalecer el pensamiento lógico y computacional, proporcionando una base teórica y práctica que permita comprender el funcionamiento de Python y prepararnos como futuros profesionales.
